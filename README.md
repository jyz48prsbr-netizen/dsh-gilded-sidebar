# Gilded Sidebar (鎏金侧栏)

A DeepSeek Harness skin derived from `black-gold-vip` by silicon-sbt (MIT).
It keeps the metallic-gold brand card in the top-left corner and additionally
colors **all left-sidebar text** (navigation items, workspace title, session
list, usage, etc.) in metallic gold. Both light and dark themes are supported.
Pure CSS — no JavaScript, no design-token overrides, no layout changes.

## Install

Install from the DSH skin center, or copy this directory into
`~/.dsh/skins/gilded-sidebar/`.
